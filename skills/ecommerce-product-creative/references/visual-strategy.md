# 视觉策略与商业版式

Agent主动选择表达，用户无需回答“想要什么风格”。提供有销售感的视觉：清楚的商品重点、有力度的短标题、合理的图形与信息组合。没有定位数据时标首测判断。商品事实受约束，摄影与排版充分创作。

## 销售结构先落地

按 [销售构图](sales-composition.md) 先填销售构图单，再选摄影和字体。工具箱是制作手段，分镜必须实际选择并描述区域与内容，不能全部落回角落标题和细横线。当前默认采用具体利益与视觉说明：使用结果全景、对应局部窗口、功能因果分层。构图以销售模块D/E/F为起点，工具箱按任务补充；不以大色块本身判断销售感，原参考商品主张不迁移。

## 先选方向，再定执行卡

按买家任务、商品特征、选择成本、证据和用户偏好，内部比较两种可行表达并自主选一个主方向；只做单项文案时跳过。用户已明确选定/批准风格时，按主文件留“沿用已定方向”及来源记录，不编造比较。不额外生成两套图片，不自动要求用户选风格。

| 决策依赖 | 可组合的表达 |
|---|---|
| 解决操作或任务 | 明确动作、接触关系、短大字、鲜明重点 |
| 氛围/穿搭/空间 | 使用者与环境、空间关系、细节和情绪短词 |
| 配置/规格/数量 | 清楚分组、参数层级、卡片或对照，信息易扫读 |
| 造型/质感 | 精致静物、受控布光、轮廓与细节，排版可克制也可鲜明 |

不将类目绑定固定风格。高级不默认米白小字，电商感不默认贴满标签，深色商品不默认黑底，户外不默认夜景。

视觉执行卡填写：`主任务与购买理由｜主方向及简短理由｜色彩作用｜摄影/动作｜字体层级｜图形和版式语言｜商品锁定点`。使用实际内容，不能仅填高级、震撼、高清等形容词。

## 版式工具箱

| 版式 | 适用任务 | 执行要点 |
|---|---|---|
| 大商品＋短标题 | 封面识别与主利益 | 商品容易辨认，准确短词有视觉力度，留出主张位置 |
| 人物/使用情境 | 理解任务、尺度和体验 | 人与商品发生有效关系，环境帮助解释；需要看细节时改近景 |
| 左右/上下分区 | 画面与说明配合 | 各区主次清楚，文字不压关键部位 |
| 四宫格/多格拼图 | 同主题的几个真实用法/细节 | 每格明确内容、机位、短词；不足四项改双栏/三格，不凑事实 |
| 矩形利益点卡片 | 快速扫读相关卖点 | 每卡一条短词配局部/图标/说明，卡片之间有阅读顺序 |
| 大细节＋标注 | 结构、接口、操作 | 标注落到真实部位，操作图优先显示接触关系 |
| 商品＋规格/选款 | 测量与比较 | 数字、单位、端点和选项准确，可用明亮干净背景 |
| 精致静物/纯色背景 | 造型、颜色、轮廓与材质视觉 | 选择背景与补光分离本体，不凭高光宣称材质 |

从工具箱为每个主题挑表达，而不是按行固定生成八张。允许四格组合在一张成品中，组合图不等于四件随附商品；必要时明确“Use examples”，实际数量按事实另标。

## 使用故事与人物

对使用场景写：`谁｜在哪里做什么｜商品怎样参与｜摆放/接触｜可见结果｜机位`。先安排活动，再选支持它的特征。

人物用于解释任务、操作、尺度或体验。远处人影或无关模特不算有效使用展示；也不要求所有商品都有人。放置、悬挂、握持、穿戴和操作必须符合本款结构，不能擅把挂钩当承重提手或补画安装件。

场景图允许环境与人物帮助叙事，不必每次巨大居中产品；封面与信息图则按识别任务保证商品可辨。产品作为营销主体不等于每张占同样面积。

## 同类目内的活动发散

开工前在 category-demand 围绕有据利益提出活动/部署语义候选，帮助判断图位价值；开工确认后再为每个L-ID细化镜头并按确认图数选择；每个候选写购买价值、结构/参数依据、镜头和新信息。不能把任何一组候选固定变成每款商品的必拍清单。不要只重复“两人桌边喝茶＋前景产品”。无需让用户逐项做设计选择，业务范围或未知功能改变时才补问。

通用发散轴：携带/移动、部署/安装、使用操作、共享/群组布置、整理/收纳、局部结构。服饰可对应穿戴/调整/搭配/收纳，收纳品对应搬放/分类/取用/归位；不把灯具镜头当通用模板。

露营照明的候选可包括背包适合挂点上的静态悬挂、手持移动、帐篷内布置、同款多灯沿一根绳分布、营地整理、桌面活动与收纳。分别核实际携挂结构和用途；不擅加扣具、不让开口挂钩凭空夹住粗带，不宣称未经确认的防脱/承重性能。类别提示便携需求，重量未知不能直接写轻量；用户确认重量后可用准确数值表达便携。

允许同款多件构成真实布置场景，即使实际是单件装：先在合同记录“同款重复演示、实际每包数量”，每件保持同SKU外观，不做成虚构连线灯串或套装。图内清楚区分实际数量与演示布置，例如实际一件装时可标“Multiple units shown; 1 unit included”。不能只在末页说明而让封面误认整组售卖。若用户不接受多件演示，换为单件场景。

群组布置展示实际用途，不自动声称覆盖面积、总亮度或多件随附。视觉可以灵动，事实与发货不变。选入整套时同时变化人物动作、景别、部署位置和阅读布局；改变同类目活动不等于跨类目串场景。

## 字体与图形

通常选择一至两套互补字体气质，建立标题、标签/参数、说明的稳定层级。主标题可紧凑粗体、窄体、圆润或精致简洁，按产品与任务选择；正文优先易读，不靠每张换字体制造变化。

决定准确的强调词和处理：矩形色块、框线、下划线、局部描边、数字放大、标签。每种图形要服务信息，不叠满所有效果。标题可换位置与结构；不要每张统一变成橙色小标题加底部白大字。

根据商品本色与环境选主色、辅助色和强调色，说明各自用途。可以鲜明商业表达，也可以精致留白；暗色商品用亮背景、轮廓光或局部补光保持可见。

## 整套节奏

统一字体系统、色彩和图形规则，按主题改变景别、机位、布局与信息密度。规划后检查是否适合组合“识别封面、使用任务、利益点组合、操作/细节、选购信息”等角色，按证据取舍。

若大部分图片同为暗背景、相同角度、相同位置、底部叠字，返回分镜改图位，而不只换天气和文字。以阅读路径和新增信息判断变化，不以凑多少种版式验收。

## 保真与构图分别管理

原始商品图提供身份，非默认构图模板；风格参考只提供视觉语言。可改变背景、摄影、动作和排版。已知结构支持的斜前、适度俯视/低机位及局部可尝试并实际回看；会清楚暴露未知接口、背面或底部时补图或换镜头。不能用水平翻转/二维拉伸冒充实物新视角，也不能承诺单图恢复准确三维。

同SKU多套创意可改变购买理由、故事、版式和文案，不改商品。探索不同方向可整体改变；因果主图测试尽量一次改一项，两个目标分开。
